Why use it

Everything in one place

No hunting through folders. The manager keeps the library, install state, logs and access panel together.

🧩

One card per mod

Seralyth and Poison bundle their builds behind a version picker, so each mod stays a single tidy card.

🏷️

Honest badges

LEGAL, ILLEGAL, or both where a menu ships mixed versions. Download buttons point to the current release files; there is no source-code button.

🏆

Ranks podium

1st, 2nd and 3rd places are called out on this page and in the loader — Seralyth Remake, Skidalyth, then Novalight.

💾

Local install counts

Counts save beside the EXE with a per-user fallback, so they survive a move or a fresh Windows profile.

🎚️

Sound you can hear

Mute with the speaker button or push the volume slider all the way to 300%. The choice is remembered.

💉

Session injection

Stage the DLL, restart the game through Steam so BepInEx loads it, then clean up when the game closes.

📄

Logs where you need them

A manager-wide change log plus a **LOG** button on every card, backed by files shipped beside the EXE.

🤖

Discord bot bundled

The manager starts the access bot on launch and stops it on exit. No second app to remember.

Access panel

Discord roles, without the mess

On startup the bot finds or creates #mod-manager-access and keeps one panel there. If someone clicks Get Loader Key without the loader-user role, they get asked how they want their code.

  1. 1
    Send code here — the code is posted in the channel.
  2. 2
    Send code in DMs — the bot DMs it, with an ephemeral fallback.
  3. 3
    I have a code — a modal validates the key and grants the role.
  4. 4
    Redeem key — grants the Buyer role and gives/reuses your LOADER-... key for Seralyth Remake Paid.

The bot never chats on its own — it only answers commands and buttons. The Paid build injects for one session and never installs or downloads a DLL.
